# Handoff notes

Kept in the repo, not the vault: this is a one-off side project. This repo is public, so these notes hold no patient data and no secrets.

## State, 2026-10-23

**Changed.**
- The released app is 2.0.1: a menu bar app, notarized. The download link gives it: https://github.com/chrisgauthier9/searchable-text/releases/latest/download/Searchable.Text.dmg
- The script is at 2.0.3, live through signed self-update (`version.txt`). Every installed app picks it up on its next click.
  - 2.0.1: each cell goes to the column its middle is on. Before this, cells overlapping the gutter by under 2 pt were dropped.
  - 2.0.2: safety net in `convertChecked`. If the character count fails, it reads the page top to bottom, then falls back to PDFKit's plain text. `tools/release.sh` breaks the column split on purpose and refuses to ship unless the safety net fires.
  - 2.0.3: `medicationRows` turns a "Medication / Instructions" list into `• name | instructions`, one row per drug.
- The install page is public on GitHub Pages, in English and French: https://chrisgauthier9.github.io/searchable-text/
  - It's generated by `tools/make_install_page.py` (style in `tools/install_page_style.css`) into `docs/`.
  - The old private claude.ai page is replaced; its `install.html` was removed.

**Decided, and why.**
- Ship script-only changes by signing and pushing (`version.txt` + `pdf2text.js.sig`), with no app rebuild. The change reaches every Mac with no reinstall and needs no notarization.
- When text is missing, copy it in the wrong order rather than drop it. Missing text in a chart is worse.
- Debug real reports only from positions, counts and word shapes, never their text. Real PDFs are copied to the scratchpad, then deleted or moved to the Trash.
