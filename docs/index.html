Searchable Text

Copies the text out of a hospital report so you can paste it into the chart, where it can be searched. Everything stays on your Mac.

Download for Mac

The download lands in your Downloads folder. Double-click it to open it.

Setting up · once, about 2 minutes

Put it on your Mac

  1. A window opens. Drag the Searchable Text icon onto the Applications folder next to it.

    Drag Searchable Text into Applications

    →

  2. Open your Applications folder and double-click Searchable Text. Your Mac asks if you want to open an app from the internet. Click Open.

    "Searchable Text" is an app downloaded from the Internet. Are you sure you want to open it?

    CancelOpen

  3. Drag Searchable Text from Applications down to your Dock, so it is always one click away.

The first time you use it

Say yes twice

  1. Open any report from the chart, then click the Searchable Text icon.

  2. Your Mac asks if Searchable Text may use Adobe Acrobat. Click Allow.

    "Searchable Text" wants access to control "Adobe Acrobat".

    Don't AllowAllow

  3. If it asks about notifications, click Allow too.

Every day

Open, click, paste

  1. Open the report from the chart.

  2. Click Searchable Text in the Dock. A note appears in the corner.

    Report text copiedClick in the chart note and press Command-V.

  3. Click in the chart note and press Command-V (⌘V).

If something looks off

"Please check it"The report has an unusual layout. The text is copied, but read it over before you save.
"No report is open"Open the report first, then click the icon again.
"This report is a scanned image"That report is a picture, so there is no text to copy.
Anything elseNothing was copied. Let Chris know.

Updates install by themselves. You never need to set it up again.

Searchable Text

Copie le texte d'un rapport d'hôpital pour que vous puissiez le coller dans le dossier, où il devient cherchable. Tout reste sur votre Mac.

Télécharger pour Mac

Le fichier arrive dans votre dossier Téléchargements. Double-cliquez dessus pour l'ouvrir.

Installation · une seule fois, environ 2 minutes

L'installer sur votre Mac

  1. Une fenêtre s'ouvre. Glissez l'icône Searchable Text sur le dossier Applications à côté.

    Glissez Searchable Text dans Applications

    →

  2. Ouvrez votre dossier Applications et double-cliquez sur Searchable Text. Votre Mac demande si vous voulez ouvrir une app téléchargée d'Internet. Cliquez sur Ouvrir.

    « Searchable Text » est une app téléchargée depuis Internet. Voulez-vous vraiment l'ouvrir?

    AnnulerOuvrir

  3. Glissez Searchable Text depuis Applications jusque dans votre Dock, pour l'avoir toujours à un clic.

La première fois

Dites oui deux fois

  1. Ouvrez n'importe quel rapport depuis le dossier, puis cliquez sur l'icône Searchable Text.

  2. Votre Mac demande si Searchable Text peut utiliser Adobe Acrobat. Cliquez sur Autoriser.

    « Searchable Text » souhaite obtenir l'accès pour contrôler « Adobe Acrobat ».

    RefuserAutoriser

  3. S'il demande pour les notifications, cliquez aussi sur Autoriser.

Chaque jour

Ouvrir, cliquer, coller

  1. Ouvrez le rapport depuis le dossier.

  2. Cliquez sur Searchable Text dans le Dock. Une note apparaît dans le coin.

    Report text copiedClick in the chart note and press Command-V.

  3. Cliquez dans la note du dossier et appuyez sur Commande-V (⌘V).

Si quelque chose cloche

"Please check it"Le rapport a une mise en page inhabituelle. Le texte est copié, mais relisez-le avant d'enregistrer.
"No report is open"Aucun rapport ouvert. Ouvrez d'abord le rapport, puis recliquez sur l'icône.
"This report is a scanned image"Ce rapport est une image : il n'y a pas de texte à copier.
Autre choseRien n'a été copié. Prévenez Chris.

Les mises à jour s'installent toutes seules. Vous n'aurez jamais à refaire l'installation.
